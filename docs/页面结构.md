```
1. https://oa.lawyers.org.cn/hall/                       OA 大厅（登录态起点）
```

## 二、技术栈（决定选择器写法）

- 前端框架：**Ext JS 2.x**（`x-grid3-row` / `x-btn` / `x-toolbar`）
- ⚠ ExtJS 的按钮 id 是**动态生成**的（`ext-gen18`~`ext-gen34`），每次加载都可能变。
  **一律用文本定位**（`button:has-text("更新排序时间")`），禁止写死 id。
- ⚠ 页面存在已知 JS 报错：`dialog.js:32 Uncaught TypeError: $.widget is not a function`
  （jQuery UI 未加载成功）。「更新排序时间」用的是**浏览器原生 `confirm()`**，不受影响。
- 页面含一个 7moor 在线客服 iframe（无关，忽略）。

## 三、★ 核心确认：置顶按钮

- 按钮文本：**「更新排序时间」**
- 选择器：`button:has-text("更新排序时间")`
- **无需先选中行**即可点击（同组「修改/删除/发布招聘/结束招聘」未选行时均为 `x-item-disabled`，
  而「更新排序时间」始终可用）
- 点击后弹**浏览器原生 confirm**，原文：

```
更新排序时间的操作在20天之内只有使用一次置顶的机会，请确认是否使用？
```

> ⚠ 实现要点：
> 1. 这是**原生 `confirm()`**，Playwright 默认静默取消 → 必须注册 `page.on("dialog")`
> 2. **每 20 天周期只有 1 次机会，点了就消耗** → 必须确认满 20 天才点，且只点一次
> 3. dry-run 模式下绝不能调用 `dialog.accept()`

## 四、列表结构

**表头（10 列）**

| # | 列名 | 单元格选择器 |
|---|---|---|
| 0 | 招聘标题 | `td.x-grid3-td-0` |
| 1 | CompanyID | `td.x-grid3-td-1` |
| 2 | 招聘单位 | `td.x-grid3-td-2` |
| 3 | 发布日期 | `td.x-grid3-td-3` |
| 4 | 结束日期 | `td.x-grid3-td-4` |
| 5 | 最新更新 | `td.x-grid3-td-5` |
| **6** | **排序时间** ★ | `td.x-grid3-td-6` |
| 7 | 招聘岗位 | `td.x-grid3-td-7` |
| 8 | 招聘人数 | `td.x-grid3-td-8` |
| 9 | 状态 | `td.x-grid3-td-9` |

- 行：`div.x-grid3-row`；选中后加 class → `div.x-grid3-row-selected`
- 分页：每页 20 条，共 3 页 41 条（该律所），**最新的一条在第 1 行**
- 时间格式：`2026-09-24 09:34`

**样例数据（firm_a 上海臻至律师事务所）**

| 招聘标题 | 发布日期 | 排序时间 | 状态 |
|---|---|---|---|
| 合伙人、提成律师、专职律师 | 2026-09-24 | 2026-09-24 09:34 | 招聘中 |
| 合伙人、专职律师、提成律师 | 2026-09-03 | 2026-09-03 08:22 | 已结束 |

> 结论：「排序时间」列可直接读取 → 20 天计时**以网站数据为准**（`source=page`），
> 本地 `state.json` 仅作兜底。

## 五、目标行的判定逻辑（阶段2 实现依据）

```
在招聘管理列表第 1 页中：
  找到 状态(列9) == "招聘中" 的行
  读取该行 排序时间(列6)
  若 (今天 - 排序时间).days >= 20  →  点击「更新排序时间」
```

若存在多条「招聘中」，取排序时间最早（最该置顶）的一条；若无「招聘中」行，跳过。
