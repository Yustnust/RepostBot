## 2026-10-02（进度盘点 + 修两个真问题）

- **发现定时任务从未真正生效**：9-29 注册后，日志只到 9-29，
  原因是任务设置 `StartWhenAvailable=false`（09:00 电脑没开就直接跳过、不补跑）。
  已用 `Register-ScheduledTask -StartWhenAvailable` 重新注册，并放开电池限制，手动触发验证通过
- **发现 `.env` 空键覆盖问题**：短信章节里有两行空的 `ALIBABA_CLOUD_ACCESS_KEY_ID/SECRET=`，
  把上面填好的真实值覆盖成空（dotenv 后者覆盖前者）→ OSS 一直连不上。已删除空值行
- **修复存储兜底缺陷**：填了 `OSS_BUCKET` 后若 OSS 上还没有 accounts.json，
  原逻辑会直接报「没有可用账号」。已抽出 `env_fallback_accounts()` 供本地/OSS 两种实现共用
- OSS 初始化仍卡在 **403 AccessDenied**：RAM 用户尚未被授予 OSS 权限（需控制台操作）
- `.env` 里 SMTP_USER / SMTP_PASS / NOTIFY_EMAIL 还是空的 → 邮件回执暂不可用
